# UI Review Skill - Búfalo Studio

This skill enforces high-end "State of AI Design" editorial standards for Búfalo Studio web applications.

## Design Audit Principles
1. **Color Palette Integrity**:
   - Primary Light Background: `#EDEDED`
   - Primary Dark Background / Dark Sections: `#171717`
   - Primary Text (Light Mode): `#171717`
   - Secondary Text & Microcopy: `#444444`
   - Accent Red (Rojo Búfalo): `#DA0037` (strict 5-10% usage limit for CTAs & highlights)
2. **Editorial Hierarchy**:
   - Headings: Display Inter / Helvetica Now, 700/900 weight, tight tracking (`tracking-tighter`).
   - Body: Clean sans-serif 400 weight, generous interlineation (`leading-relaxed`, 150%).
   - Technical Micro-copy: Monospace (JetBrains Mono / Roboto Mono), `#444444`, uppercase, `tracking-widest`.
3. **Micro-interactions**:
   - 2px Rojo Búfalo expanding underline on link hover.
   - Smooth magnetic button hover state with crisp feedback.
   - Fluid section theme transitions without layout shifts.

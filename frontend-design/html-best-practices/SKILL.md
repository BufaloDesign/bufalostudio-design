# HTML Best Practices Skill - Búfalo Studio

## Rules & Standards
1. **Semantic Hierarchy**:
   - Single `<h1>` in Hero section (`Fuerza visual. Precisión de datos.`).
   - `<h2>` for Chapters (01 INGENIERÍA, 02 ESTÉTICA, 03 INTELIGENCIA, Cierre).
   - Use `<main>`, `<header>`, `<section>`, `<article>`, `<footer>` appropriately.
2. **SEO & Metadata**:
   - Open Graph tags, Twitter Card tags, and Schema.org `Organization` metadata.
   - Descriptive `alt` tags for all editorial photography (`alt="Fotografía de producto de alta gama Búfalo Studio"`).
3. **Performance**:
   - Preload primary fonts (Inter, JetBrains Mono).
   - Lazy load images below the fold using native `loading="lazy"` or WebP/AVIF pictures.
